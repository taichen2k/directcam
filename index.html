탈모모니터링Cam

폰 두 대를 직접 연결해 한 대로 찍고, 다른 한 대로 실시간으로 보면서 셔터를 누릅니다.

카메라폰에 뜬 QR을 모니터폰 기본 카메라로 찍으면 바로 연결됩니다. 영상과 사진은 서버를 거치지 않고 두 폰 사이에서 직접 오갑니다. 같은 와이파이에 있으면 가장 빠릅니다.

설치 창이 안 뜨면 브라우저 메뉴에서 설치하세요.
크롬: 오른쪽 위 ⋮ → 홈 화면에 추가 또는 앱 설치
삼성 인터넷: 아래쪽 ≡ → 현재 페이지 추가 → 홈 화면
