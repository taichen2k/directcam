이용 안내
  1. 카메라 폰에 뜬 QR 코드를 모니터 폰의 기본 카메라로 비추면 바로 연결됩니다.
  2. 사진과 영상은 서버를 거치지 않고 두 폰 사이에서만 주고받습니다.
  3. 동일한 Wi‑Fi 또는 한쪽 폰의 핫스팟에 두 개의 폰을 연결한 뒤 시작하세요.

설치 창이 안 뜨면 브라우저 메뉴에서 설치하세요.
크롬: 오른쪽 위 ⋮ → 홈 화면에 추가 또는 앱 설치
삼성 인터넷: 아래쪽 ≡ → 현재 페이지 추가 → 홈 화면
아이폰·아이패드 사파리: 공유 버튼(□↑) → 홈 화면에 추가

대기

카메라 폰과 연결

카메라 폰 화면의 QR 코드를 이 폰의 기본 카메라로 비추면 자동으로 연결됩니다. 카메라 폰에 표시된 6자리 코드를 입력해도 됩니다.

이번에 찍은 사진 0장

카메라 폰에 자동으로 저장했습니다. 브라우저 설정 때문에 저장되지 않았다면 「모두 저장」을 눌러 주세요.

두 폰이 직접 연결되지 않습니다

크롬으로 쓰는 폰이 있다면, 그 폰에서 아래 권한을 켜 주세요. 처음 한 번만 하면 됩니다.

  1. 폰 설정 → 애플리케이션 → Chrome → 권한
  2. 주변 기기(근처 기기)를 허용
  3. 크롬을 완전히 닫았다가 다시 열기

그래도 안 되면 두 폰이 같은 와이파이인지 확인하거나, 한쪽 폰의 핫스팟에 다른 폰을 연결해 보세요. 엣지나 삼성 인터넷으로 열어도 됩니다.
